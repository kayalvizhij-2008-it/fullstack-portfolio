# 🚀 Full-Stack Personal Portfolio Website

A recruiter-ready full-stack personal portfolio website built using modern frontend and backend technologies. This project showcases professional projects, technical skills, responsive UI design, backend API integration, and MongoDB database connectivity.

---

# 🌟 Project Highlights

* Modern Responsive UI/UX
* Full-Stack MERN-style Architecture
* Backend REST API Integration
* MongoDB Database Connectivity
* Dynamic Contact Form
* Professional Project Showcase
* Deployment Ready Architecture
* Recruiter & Internship Ready Design
